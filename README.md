# GAP

**You need a GAP.** 给连续刷短视频的时间，留一个间隔。

GAP 是一个 Android 本地应用使用额度工具。它将每日预算拆成小份：默认每天 60 分钟，每份使用 5 分钟，用完休息 10 分钟。当前初版版本为 **0.1.0**，应用名称 GAP，包名 `app.gap.clarity`。

这是首个公开测试版本，对外版本统一从 0.1.0 开始。内部构建号为27，用于延续开发版本的升级顺序；已有同签名安装可覆盖更新。

## 功能

- 选择一个已安装应用，默认抖音；无需自己采样或制作页面规则。
- 前台使用才扣时，离开或锁屏暂停；一份额度可以分多次打开使用。
- 每份耗尽后进入 GAP，冷却结束最多恢复一份，不囤积，受每日余额限制。
- 每天本地时间零点重置每日与本轮额度、旧冷却。
- 修改冷却时长后立即扣除已经等待的时间，等够则恢复一份。
- 全屏举牌休息页、固定字位倒计时、进退场动效和一次性短提示音。
- 首次四页使用说明、状态检查、红色异常提示、可选状态通知。
- 三次确认暂停保护，手动恢复；暂停不会补发使用额度。
- 黑白桌面图标、浅色主页、设置式页面过渡。

## 安装和授权

下载本仓库 **Releases** 中的 `gap-0.1.0.apk`，不是 Code → Download ZIP 中的源码。

1. 安装并阅读首次说明。
2. 进入“权限与运行检查”，阅读解释后前往系统无障碍设置。
3. 开启“GAP · 使用额度保护”。侧载应用如果被系统限制，按手机提示从应用信息允许受限设置。
4. 一加设备可检查耗电管理中的后台活动设置。不同系统入口可能不同。
5. 回到 GAP，确认状态，再手动完成一次真实拦截测试。

同包名、同签名的更新可覆盖安装。其他美术候选和旧版“片刻”是独立应用，数据与授权不会导入。测试时只开启一个保护服务。

## 修改界面文字

打开 [`app/src/main/res/values/strings.xml`](app/src/main/res/values/strings.xml)，搜索目前屏幕上的文字，只修改文字内容，保存并重新构建 APK。

例如把 `home_section` 的“你的使用节奏”改成“按自己的节奏”。不需要修改 Java。完整步骤见 [修改文案](docs/EDITING-TEXT.md)，全部名称见 [文案索引](docs/COPY-CATALOG.md)。

图片中本子上的手写字是图片像素，不能通过 strings.xml 修改。

## 构建

环境：Python 3.9+、JDK 17+、Android SDK Platform 35 和 Build-Tools 35.0.0 或更高。没有额外 Python 包、Gradle 或网络运行时依赖。初次 SDK 安装需要网络。

```powershell
py build.py --sdk "你的Android SDK目录" --jdk "你的JDK目录"
```

输出在 `dist/gap-0.1.0.apk`。默认会生成仅用于本地开发的签名，它不能覆盖使用其他签名安装的 APK；不要为了测试而卸载现有应用，否则会丢失数据。要继续更新原有安装，需要保管并使用原签名。完整说明见 [构建与签名](docs/BUILD.md)。

仅运行规则检查：

```powershell
py build.py --test-only --jdk "你的JDK目录"
```


## 隐私与权限

没有 INTERNET 权限，无账号，无联网统计。额度与设置保存在本机。无障碍服务取得前台窗口根节点包名以识别目标应用，不遍历正文、不保存输入、不截图。通知权限可选。详见 [隐私说明](PRIVACY.md)。

## 当前边界

这是初版，用户已在一加 13T 上参与安装和手动测试；没有覆盖所有品牌或完成长期稳定性验证。旧版曾出现无障碍服务数小时后故障，当前仍未实施专项后台重构，不保证持续保活。系统撤权、强行停止、卸载、清除数据、改系统时间都可能影响保护。

同时保护一个应用；分屏、画中画、跨设备统计不保证。它是自我约定工具，不能保证不可绕过。系统设置、桌面和输入法仍使用 Android 自身行为。

此次发布整理已通过规则检查、编译、签名及默认文案一致性检查；这些不能替代真机长期实测。已知问题及后续方向见 [ROADMAP.md](ROADMAP.md)。
